# Design drift from the baseline

This note compares the package designs from baseline commit `9194f02` with the folded designs. The package capability-disposition tables remain authoritative: [Blueprint](blueprint-design.md#capability-disposition), [LLM](llm-design.md#capability-disposition-and-friction), [Fabric](fabric-design.md#baseline-capability-disposition-and-oracle-validation), [Grind](grind-design.md#capability-disposition-against-9194f02), [Relay](relay-design.md#5-baseline-capability-disposition-and-friction), [Saga](saga-design.md#capability-disposition), [Sinal](sinal-design.md#capability-disposition), and [Warden](warden-design.md#48-full-capability-disposition). Full capability scope is distinct from the [initial public facade](PUBLIC-API.md). Open or deferred means implementation backlog, not removed scope. Authors report no intentional feature loss; this is not proof of behavioral parity.

## HTTP ownership update — 29 September 2026

The owner selected the independent [HTTP Gun package](http-gun-design.md). Generic HTTP/TLS, pooling, byte-stream ownership and cassette record/playback move to that package when implemented. LLM Wire retains provider request/response semantics and bounded semantic streaming. Fabric or another caller owns conversation and continuation persistence. This supersedes older LLM continuation/transport ownership statements in the baseline comparison below. No HTTP Gun implementation or downstream migration is claimed by this design update. The [oracle ledger](research/http-gun-oracles.md) records reusable donor behavior and unverified obligations.

## Warden backend update — 30 September 2026

Implementation evidence and owner decisions (Warden repository `docs/decisions.md`, D7 and D10–D12) revised the [Warden design](warden-design.md). The default backend is now Gleam-native on `gose`/`kryptos`: Warden owns discovery, JWKS caching, provider requests and OpenID claim rules, while cryptography stays in those libraries. `oidcc` 3.9.0 was then removed as a backend before the first release (D13) and remains a test-only differential oracle. Warden's bounded HTTPS transport is written in Gleam over OTP `ssl` until `http_gun` gains a destination-policy hook; observations are typed `sinal` events. Providers that omit PKCE method metadata are accepted only through an explicit, confidential-client-only policy. No capability was removed; the native backend adds refresh without an ID token. Parity was shown on the Warden repository's local suites and conformance plans, which is regression evidence, not certification.

## Retained scope and ownership changes

- **Blueprint** owns JSON Schema-aware values, codecs, schemas, and runtime contracts moved from Relay and Fabric’s schema paths. Ordinary JSON serialization prefers standard Gleam encoders/decoders; optional reusable codecs remain independent of Blueprint. Its exact `Number` policy applies within its schema/value model; migration from integer-only `Value.Int`, parsing, broader schema vocabularies, and legacy compatibility remain unfinished. Source generation remains future tooling and is excluded from the initial facade.
- **Standalone LLM** receives provider calls, stream grammar, continuation, transport, and adapter responsibilities formerly inside Fabric. OpenAI Responses and Anthropic Messages remain researched targets; Google remains a baseline target without a pinned oracle. Upstream suites and live adapters have not established provider parity.
- **Fabric** retains its agent loop, contextual tools, action policy, approvals, and continuation. Typed DAG ownership moves to Saga, durable delivery to Saga/Grind, and provider behavior to LLM. The baseline retrieval/vector/document-processing exclusions are inherited. Reducer correspondence, historical review forks, suspension inside Saga, streaming-agent composition, and concrete sub-agent execution remain unresolved.
- **Saga** retains typed composition, parallel-work requirements, compensation, retry, and runtime-schema graphs; it also accepts Fabric's validation, reducers, historical forks, and suspending-agent integration as work to prove. Unrestricted closure plans, value-dependent branching, durable-definition eligibility, and compensation after successful execution remain unresolved rather than removed.
- **Grind** retains the full Oban-oriented queue scope, including raw dependency DAGs, batches, chunking, recording/relay, advanced limits, plugins, SQLite, and test modes. Saga owns typed compensated workflows; Grind owns delivery. Raw-workflow equivalence, SQLite semantics, uniqueness breadth, and queue-feature parity remain explicit risks.
- **Relay** retains server and client protocols, resources, prompts, authorization, transports, test support, and conformance obligations. The initial modern server uses the pinned 2026-07-28 schema; legacy compatibility and remaining families stay backlog. The baseline proposed eight Relay distribution packages. The initial distribution keeps their responsibilities as internal Relay modules; a later physical split remains deferred until target, dependency, or release-cadence evidence justifies it. This changes packaging only: server, client, stdio, HTTP, authorization, test-kit, conformance, and pure-core capabilities all remain Relay scope.
- **Sinal** retains typed events, handlers, spans, and package-owned observations. Actor-per-event dispatch is replaced by a synchronous native `:telemetry` registry. Native atom/map conversion and interoperability remain unverified.
- **Warden** retains OIDC/OAuth operations with transaction revisions, custody-owned sessions, and refresh recovery. It removes unsupported security assumptions: AEAD cookies do not prove shared single-use replay protection, raw backend errors are not exposed, and historical `oidcc` certification does not transfer to this wrapper. Provider, cryptographic, HTTP, and storage claims remain open.

## Dependency correction

The user’s correction removes the earlier mandatory Blueprint foundation for ordinary JSON. Protocol envelopes, job payloads, workflow persistence, telemetry, and identity do not require JSON Schema or Blueprint. Tool declarations, structured output, and runtime schema validation still use Blueprint where schema support is required. Laboratory central imports remain prototype convenience; this documentation change makes no runtime migration or new codec-package claim.

## Behavior changes and unresolved loss

Sinal maps ordinary `Result.Error` completion to a span stop rather than an exception event, and makes missing detach ownership (`NotAttached`) explicit. Relay separates the modern server slice from older protocol revisions. Warden quarantines uncertain refresh outcomes and requires an owner-confirmed, revision-bound consume step before code exchange. These are deliberate contract refinements recorded in the package designs, not claims that upstream behavior has been reproduced.

Potential loss is limited to unresolved equivalence at reassigned boundaries: Fabric reducer and review-fork semantics; Saga suspension, arbitrary local closures, durable eligibility, and post-success compensation; Grind raw workflow and advanced queue parity; Relay's unimplemented client/resource/legacy families; and Warden's unimplemented provider operations and conformance profiles. Inherited exclusions, including Fabric retrieval/RAG and the baseline runtime exclusions listed by Saga and Warden, are not new deferrals. Pinned references and unrun-oracle limits are recorded with each capability table. No package has a completed production-parity claim from this consolidation.
