# Ecosystem design coverage

- Oversight has three contexts: composition, applications and evidence. Package runtime designs live in their owning repositories; their presence in this inventory does not create an Oversight runtime.
- `captured` identifies a design owner. It does not claim that every described intended capability has been implemented or verified.
