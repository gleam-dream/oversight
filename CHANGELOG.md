# Changelog

## Unreleased

- Composition applications exercise the public APIs of nine core libraries and two retained PostgreSQL adapters against local peers and disposable databases.
- Package repositories own their detailed designs. Oversight owns composition contracts, application responsibilities and the limits of the retained evidence.
- Native design layers, canonical vocabularies, ADRs and coverage maps replace scattered construction plans and review snapshots. The renderer and agent context loader use pinned tooling.

[ADR 0001](docs/adr/0001-own-designs-in-package-repositories.md) records the documentation ownership change. The other [ADRs](docs/adr/) retain material ecosystem decisions. Package behavior changes belong to their owning repository's release notes and decision records.
