# Gleam Dream oversight

- This repository coordinates a proposed ecosystem of production Gleam libraries. Production execution targets Erlang/OTP first.
- The [composition feedback](docs/composition/FEEDBACK.md) is the current cross-package review. It synthesizes eight runnable [composition apps](apps/README.md) and nine [package API cards](docs/composition/scan/), and orders the changes that would reduce composition glue.
- Start with the [ecosystem creation plan](ECOSYSTEM-PLAN.md) for recommended responsibilities, sequencing, and acceptance evidence. It is a planning proposal, not evidence that the APIs compile or the libraries are implemented.
- Use the [public API guidelines](PUBLIC-API-GUIDELINES.md) to review new package facades and consumer evidence. The rules apply across packages without introducing a shared runtime or mandatory dependency.
- The [initial public API freeze](PUBLIC-API.md) records the intended package facades. The [public API coverage inventory](API-COVERAGE.md) retains the full capability scope, evidence, and runtime obligations; Open and Partial rows remain backlog.
- The [design drift record](DESIGN-DRIFT.md) summarizes ownership changes against the original baseline, behavior refinements, and unresolved equivalence without replacing each package's capability table.
- The [exploration inventory](EXPLORATION.md) records the original intent and questions. The [research directory](research/) records source-backed findings and the limits of the inspection.
- The nine package design documents ([HTTP Gun](http-gun-design.md), [Blueprint](blueprint-design.md), [standalone LLM](llm-design.md), [Fabric](fabric-design.md), [Grind](grind-design.md), [Relay](relay-design.md), [Saga](saga-design.md), [Sinal](sinal-design.md), and [Warden](warden-design.md)) record each boundary's full scope, initial facade, reassigned capabilities, and reference evidence. A narrower initial facade does not remove full-scope backlog.
- The [interface stress exploration](playground/interface_lab/STRESS-TESTS.md) maps independent and combined use cases to compiler probes, small API corrections, and remaining design gaps.
- The [refinement status](playground/interface_lab/REFINEMENT-STATUS.md) tracks subsequent graph, schema/catalog, and observation experiments and the remaining acceptance questions.
- The [API control contract](docs/implementation/api-control/contract.md) records the current implementation direction. Its [migration guide](docs/implementation/api-control/migration.md) names consumer updates, and the [cross-package pilot](playground/ecosystem_pilot/README.md) compiles and runs the public composition path.
- The [release-readiness review](docs/implementation/api-control/release-readiness.md) records consumer documentation corrections, local gate results, branch integration, and remaining publication prerequisites.
- [HTTP Gun](http-gun-design.md) defines the independent Gun-backed HTTP client, streaming, and cassette record/playback direction. The [implementation prompt](docs/implementation/http-gun-prompt.md) is ready for a construction agent; [reference evidence](research/http-gun-oracles.md) distinguishes inspiration from tested parity.
- [Dream HTTP Client adoption](docs/implementation/api-control/dream-http-refinement.md) is deferred pending upstream discussion and explicit decisions about remaining transport limitations.
- Use Blueprint only when JSON Schema is needed. Ordinary JSON prefers standard Gleam encoders/decoders; optional reusable codecs remain independent of Blueprint and schema support. Laboratory imports do not mandate production dependencies.
- Use the [repository instructions](AGENTS.md) for the Nix toolchain. The retained [interface playground](playground/interface_lab/README.md) explores the proposed contracts with positive and negative compiler examples; it does not implement the production libraries.
