Three things to notice

Sinal

Observability is built in

{{sinalCount}} of the 11 other libraries emit Sinal events. Attach observers once and you can see inside HTTP calls, jobs, workflows and agents alike.

JSON Blueprint

Data crossing a boundary is typed

Wherever data meets a model, a protocol or a stored record (LLM Wire, Relay, Fabric, Decisions), JSON Blueprint codecs describe its shape and generate the schema.

HTTP Gun

One door to the network

LLM Wire, Relay, Hellhound and Fabric all reach the network through an HTTP Gun client that your application starts. One place to set limits and destination rules.

Storage is opt-in. Most libraries run in memory out of the box. PostgreSQL support comes as separate adapter packages (Saga, Fabric, Hellhound, Correio and Decisions each have one), and they borrow your connection pool. Grind is the exception: it is built on PostgreSQL.
